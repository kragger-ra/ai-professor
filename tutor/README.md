# Tutor v2

Переписанный ИИ-тьютор: **один процесс, линейный голосовой конвейер**.
Заменяет легаси-архитектуру на 4 процесса + `multiprocessing.Manager`,
унаследованную от стримингового агента NetTyan.

## Конвейер

```
capture/STT  --input_q-->  agent  --tts_q-->  playback
     |                                            ^
     +------------------ interrupt ---------------+
```

Один процесс, рабочие потоки, обычные `queue.Queue`, один `threading.Event`
прерывания. Ни Manager, ни IPC, ни прокси.

## План по фазам

| Фаза | Содержание | Статус |
|---|---|---|
| 1 | Спина: потоки, очереди, прерывание, push-to-talk гейт (заглушки) | ✅ готово |
| 2 | QA-база: STT, RAG, мета пред-полётом, промпт, стрим LLM, Vosk-TTS, объект «Ответ» | ✅ готово |
| 3 | Перебивание + возврат (стек на 1 уровень) | — |
| 4 | Вложенность: стек 3 уровня, парковка отложенных вопросов | — |
| 5 | Адаптивный слой: регистр речи, чекер мини-лекций, тюнинг длины, роутер команд | — |
| 6 | Память между сессиями, профили, эмбиент, FX, Gradio-панель | — |
| 7 | Зачистка: удалить легаси `src/` | — |

## Запуск

```
python -m tutor.app            # реальный конвейер (микрофон -> RAG -> LLM -> Vosk)
python -m tutor._smoke_phase2  # автотест мозга: текстовый вопрос -> ответ (нужны LM Studio + OpenAI)
python -m tutor.brain.answer   # автотест объекта «Ответ» и стека
```

`tutor.app` требует запущенные LM Studio (эмбеддинги RAG) и Vosk-TTS сервер,
плюс доступ к OpenAI API (или локальной модели).
