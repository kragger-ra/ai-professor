## 2026-05-25 — Автогенерация учебного пособия из корпуса при сборке курса

**Суть.** Когда пользователь через `CourseBuilderDialog` (`board/course_builder.py`) загружает сырой корпус (PDF/DOCX/MD/TXT), Builder сейчас только нормализует файлы в `.md` и пишет `course_config.yml`. FAISS-индекс строит тьютор при активации. Идея: вторым выходом Builder'а делать «методичку» — линейный учебный материал по курсу, по которому студент может идти самостоятельно (как PDF-пособия `_dswok_pdf/*.pdf`, только собранные автоматически из любого корпуса, без ручного перевода).

**Что нужно.** Map-reduce пайплайн поверх канонического `.md` Builder'а:
- A — extract терминов и тезисов по чанкам параллельно (как 18 субагентов в DSWoK)
- B — cross-link проход: один LLM-вызов, видит весь список → размечает связи между терминами
- C — сшивка в `<short>_textbook.md` с гиперссылками-якорями между связанными узлами
- D — конвертация в PDF через готовый `_dswok_pdf/build_pdfs.py` подход (chrome `--print-to-pdf` + KaTeX inline)

Файл `<short>_textbook.pdf` кладётся в папку курса. Ридер борда (`board/doc_window.py`) подхватит автоматически — там уже PDF.js v3.11 с RMB-меню «Объяснить / Прочитать / Комментарий».

**Что готово.** Builder, canonical `.md`, PDF-сборка (`_dswok_pdf/build_pdfs.py`), ридер документов с инжектом в LLM-контекст — всё это уже есть. Дописать только LLM-пайплайн A→B→C.

**Tradeoffs.**
- **Hallucination risk.** Методичка ≠ корпус, если не приклеить grounding. Нужен faithfulness-чек по образцу `research/eval_results/03_faithfulness.md`: каждый абзац ссылается на чанк-источник.
- **Стоимость.** Корпус DSWoK-масштаба (~57k слов) — десятки центов через gpt-5.4. Книга — единицы $. Не блокер, но юзер должен видеть оценку перед запуском.
- **«Связи» — самая хрупкая часть.** Простой prompt «выдели связанные термины» даст поверхностные cross-refs. Настоящий knowledge graph (узлы=термины, рёбра=типизированные отношения «является частью / противоположен / предшествует») — отдельная фаза и +50% к стоимости. Для v1 — текстовые «см. также X».
- **Builder сейчас офлайн.** Добавление LLM-вызовов привязывает к OpenAI/сети. Решение: галочка «Сгенерировать учебное пособие», по умолчанию выкл.

**Scope-варианты:**
- v1 — overview (5-10 страниц, концептуальная карта, cross-refs текстом). Одна map-reduce итерация. ~1 сессия.
- v2 — полная методичка (50+ страниц, главы с задачами и примерами). Дополнительная фаза «развёртка раздела до главы». 2+ сессии.
