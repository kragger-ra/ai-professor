# Голосовая проверка работоспособности — Тьютор v2

Walkthrough по всему функционалу v2 голосом. Занимает ~15 минут.
Отмечай пункты по мере прохождения. Расхождение — запиши номер шага и
приложи фрагмент лога.

Весь лог дублируется в `tutor_v2.log` (перезаписывается при каждом
запуске). Лог Vosk-TTS — в `vosk_tts.log`.

Каждый ход в логе есть строка `[META-AGENT] {...}` — по ней видно
`register`, `length`, `mood`, `ref` для текущей реплики. Строка
`[agent] answering …` показывает `register N` и `cap N` — текущий
регистр речи и лимит длины ответа.

Список фраз-команд — в `docs/VOICE_COMMANDS.md`.

---

## Подготовка

- [ ] LM Studio запущен (порт 22227, модель bge-m3 — эмбеддинги RAG)
- [ ] Запустить `start_tutor_v2.bat` — поднимет Vosk-TTS, затем профессора
- [ ] Дождаться фразы **«Профессор готов. Спрашивай.»** — это сигнал
      готовности и одновременно сквозная проверка цепочки TTS
- [ ] В консоли есть строка `[app] pipeline up`

Если фразы нет ~2 минуты — смотри `tutor_v2.log` и `vosk_tts.log`.

## Блок 1 — Базовый Q&A

- [ ] **1.1** Задай простой вопрос по активному курсу.
  Звук: короткий ответ по делу, не длиннее 3-4 предложений.
  Лог: `[agent] answering (fresh) — depth 1, register 2, cap 4`;
  строки `[rag]` с найденным контекстом.
- [ ] **1.2** Задай вопрос вне курса (бытовой).
  Звук: профессор отвечает, но предупреждает, что это не из материалов
  курса.

## Блок 2 — Перебивание и возврат

- [ ] **2.1** Задай вопрос, дождись начала ответа, перебей новым
  вопросом (говори громко поверх речи профессора).
  Звук: профессор замолкает и отвечает на новый вопрос.
  Лог: `[capture] speech started (… interruption=True)`,
  `[agent] answering (nested) — depth 2`.
- [ ] **2.2** Скажи «продолжай».
  Звук: профессор возвращается к прерванному ответу и дочитывает
  остаток. Возврат мгновенный — без паузы на генерацию.
  Лог: `[agent] resumed`.
- [ ] **2.3** Перебей 3 раза подряд (вложенность 3 уровня), затем
  перебей четвёртый раз.
  Звук на 4-м: «Давай закончим начатое, а про твой вопрос поговорим
  чуть позже, иначе можем запутаться.»
  Лог: `[agent] depth cap (3) — parked`.
- [ ] **2.4** Дослушай ответы до конца, ничего не говори.
  Звук: профессор сам предложит вернуться к отложенному вопросу.

## Блок 3 — Стоп

- [ ] **3.1** Задай вопрос, во время ответа скажи «стоп».
  Звук: профессор немедленно замолкает и сам НЕ продолжает.
  Лог: `[agent] stop command — staying silent`.

## Блок 4 — Мини-лекция

- [ ] **4.1** Скажи «расскажи подробнее про `<тему курса>`».
  Звук: «Это будет мини-лекция — большой развёрнутый рассказ. Зачитать?»
  Лог: `[agent] mini-lecture offered`.
- [ ] **4.2** Ответь «да».
  Звук: длинный развёрнутый рассказ (что это, как работает, пример,
  типичные ошибки).
  Лог: `[agent] answering (fresh, mini-lecture)`.
- [ ] **4.3** Снова «расскажи подробнее про `<другую тему>`», ответь
  «нет».
  Звук: короткий обычный ответ по теме.

## Блок 5 — Манера

- [ ] **5.1** Скажи «расскажи проще».
  Звук: «Хорошо, объясню проще.» Лог: `[commands] manner -> simpler`.
- [ ] **5.2** Задай вопрос — ответ заметно проще по лексике.
- [ ] **5.3** Скажи «расскажи подробнее» (БЕЗ названия темы).
  Звук: «Хорошо, развёрнуто.» Лог: `manner -> detailed`.
- [ ] **5.4** Скажи «как обычно».
  Звук: «Хорошо, как обычно.» Лог: `manner -> neutral`.

## Блок 6 — Адаптивный регистр

- [ ] **6.1** Задай 3-4 вопроса подряд нарочито профессиональным языком
  (термины, точные формулировки).
  Лог: значение `register N` в строках `[agent] answering` растёт ход
  за ходом к 4-5.
  Звук: профессор свободнее использует терминологию.
- [ ] **6.2** Задай 3-4 вопроса нарочито простым, бытовым языком.
  Лог: `register N` снижается к 1-2.
  Звук: профессор переходит на простые слова.

## Блок 7 — Тюнинг длины

- [ ] **7.1** Задай следующий вопрос с пометкой о длине, НЕ используя
  слово «короче» (оно сменит манеру). Например:
  «ты говоришь слишком длинно, `<вопрос>`».
  Лог: значение `cap N` в `[agent] answering` уменьшилось.
  Звук: ответ заметно короче.
- [ ] **7.2** Аналогично с «и это всё? `<вопрос>`» или «хотелось бы
  поподробнее, `<вопрос>`».
  Лог: `cap N` вырос.

## Блок 8 — Курсы и смена курса

- [ ] **8.1** Скажи «какие курсы есть».
  Звук: профессор перечисляет доступные курсы.
  Лог: `[commands] list courses`.
- [ ] **8.2** Скажи «загрузи курс `<второй курс>`».
  Звук: «Загружаю предмет …, минуту» -> «Готово, загружено N
  фрагментов. Могу преподавать предмет …».
  Лог: `[commands] load subject`, `[rag] reload_from_path`.
- [ ] **8.3** Задай вопрос по новому курсу — ответ опирается на новый
  материал.

## Блок 9 — Мета-агент (опционально)

- [ ] **9.1** Сразу после ответа спроси неполной фразой: «а это как
  работает?»
  Лог: в строке `[META-AGENT]` поле `ref` указывает на тему предыдущего
  ответа.
  Звук: профессор отвечает по той теме, а не про слово «это».
- [ ] **9.2** Скажи что-то растерянное: «я совсем не понял, можно
  ещё раз?»
  Лог: `[META-AGENT]` поле `mood` = «растерян».
  Звук: профессор снижает темп и объясняет проще.

## Блок 10 — Завершение

- [ ] **10.1** Нажми Ctrl+C в консоли профессора.
  Лог: `[app] shutting down`.
- [ ] **10.2** Закрой окно Vosk-TTS.
