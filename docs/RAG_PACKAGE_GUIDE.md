# Подготовка учебных материалов (RAG-пакет)

Тьютор отвечает по содержимому **RAG-индекса** (Retrieval Augmented Generation).
Чтобы он «знал твой курс», нужно собрать пакет из своих `.md` / `.txt` файлов
и положить его в любую папку — тьютор загрузит её голосом или из UI.

---

## 1. Что подходит как материал

| Подходит | Не подходит |
|---|---|
| `.md` (Markdown) | `.pdf` (нужно сначала конвертировать) |
| `.txt` | `.docx`, `.doc` |
| Текстовые конспекты лекций | Изображения / схемы |
| Главы учебника как Markdown | Видео / аудио |
| Распечатки слайдов в текст | Презентации `.pptx` |

**Рекомендуемая длина одного файла:** 500–5000 слов. Слишком короткие фрагменты дают «бедный» контекст; слишком длинные хуже режутся по абзацам.

**Структура текста:**
- Заголовки `#`, `##`, `###` — помогают тьютору ориентироваться
- Один абзац = одна мысль (тройной перенос разделяет на чанки)
- Формулы оставляй текстом или в LaTeX (`$$x^2 + y^2 = z^2$$`) — Vosk их пропустит, но контекст для LLM сохранится

---

## 2. CLI-упаковка через `prepare_rag_package.py`

Скрипт берёт «сырую» папку, копирует тексты и пишет `course_config.yml` —
самодостаточный пакет, который можно унести на флешке или раздать студентам.

### Минимальный пример

```powershell
uv run tools\prepare_rag_package.py `
    --source D:\my_lectures `
    --out D:\courses\linal `
    --course-name "Линейная алгебра" `
    --course-topic "векторы и матрицы"
```

### Полный пример с настройкой стиля

```powershell
uv run tools\prepare_rag_package.py `
    --source D:\raw_kb\linal `
    --out D:\courses\linal `
    --course-name "Линейная алгебра" `
    --course-topic "векторы, матрицы и линейные операторы" `
    --short-name "ЛинАл" `
    --teaching-style "строго и формально, с акцентом на доказательства" `
    --audience "студент технической специальности" `
    --overwrite
```

> Без uv: `.venv\Scripts\python.exe tools\prepare_rag_package.py ...`

### Параметры

| Флаг | Обязателен | Что делает |
|---|---|---|
| `--source` | ✔ | Папка с исходными `.md` / `.txt` (читает рекурсивно) |
| `--out` | ✔ | Куда положить упакованный курс. Должна быть пустой, либо `--overwrite` |
| `--course-name` | ✔ | Полное название (в промпте) |
| `--course-topic` | ✔ | Тематика для системного промпта |
| `--short-name` | — | Короткое имя для голоса (defaults to `--course-name`) |
| `--teaching-style` | — | Однострочное описание манеры (defaults: «дружелюбно») |
| `--audience` | — | Целевая аудитория (defaults: «студент») |
| `--overwrite` | — | Разрешить запись в непустую `--out` |

### Что получается на выходе

```
D:\courses\linal\
├── glava_1.md
├── glava_2.md
├── seminar_3.txt
└── course_config.yml     ← создаётся скриптом
```

`course_config.yml`:
```yaml
course:
  name: "Линейная алгебра"
  topic: "векторы, матрицы и линейные операторы"
  short_name: "ЛинАл"
  audience: "студент технической специальности"
persona:
  teaching_style: "строго и формально, с акцентом на доказательства"
```

Этот YAML тьютор применяет к промпту преподавателя — фразы вроде «как мы говорили на курсе X» становятся осмысленными.

## 3. Загрузка курса в Тьютор

После того как пакет готов:

### Вариант А: короткая команда (рекомендуется)

Если пакет лежит в одной из стандартных папок (`courses/`, `samples/`, `data/courses/`), достаточно произнести его `short_name`:

> «Загрузи курс **линал**»

Tutor сканирует все три директории, ищет `course_config.yml`, сопоставляет с произнесённым именем (case-insensitive, с подстрокой для коротких ник-неймов вроде «вышмат» → «вышмат-2026»). Найдёт — загрузит без диктовки пути.

**Шаблоны короткой команды:**

| Действие | Голос |
|---|---|
| Заменить курс | «**загрузи** курс X» |
| Дополнить | «**добавь** курс X» |
| То же | «**подгрузи** модуль X» |

Слова `курс`/`предмет`/`модуль`/`тему`/`дисциплину` взаимозаменяемы.

### Вариант Б: длинная команда с явным путём

Если пакет лежит в произвольной папке вне репо — указывай путь явно:

> «Загрузи предмет **ЛинАл** из папки **D двоеточие курсес линал**»

STT транскрибирует `D:\courses\linal` как «д двоеточие курсес линал». Слово «двоеточие» обязательно — иначе путь не парсится.

### Вариант B: через CLI без голоса

Можно изменить активный курс напрямую через `data/current_course.json`
(подмонтируется без перезапуска благодаря mtime-кэшу):

```powershell
echo '{"path": "D:\\courses\\linal"}' > data\current_course.json
```

Но RAG-индекс при этом не перестроится — нужен ручной запуск reload (или просто голосовой команды).

---

## 4. Проверка что курс активен

После загрузки:

> 🎤 «Что мы изучаем?»
> 👂 «На курсе линейной алгебры мы разбираем векторы и матрицы…»

Если тьютор всё ещё упоминает PersonaLab / NetTyan / дефолтный курс — значит `course_config.yml` не подхватился. Проверь:

```powershell
type data\current_course.json
```

Должно быть `{"path": "<твой путь>"}`. Если нет — повтори голосовую команду.

---

## 5. Переключение между курсами

Можно держать несколько пакетов и переключаться:

```
D:\courses\
├── linal\
├── physics\
└── ml_basics\
```

> «Загрузи предмет физика из папки D двоеточие курсес физика»

Полная замена индекса. Если хочешь сохранить материалы нескольких курсов в одном RAG — используй «добавь» вместо «загрузи».

---

## 6. Известные ограничения (баги для следующей версии)

- **Многострочные формулы LaTeX** иногда режутся посреди формулы (chunk boundary). Тьютор воспроизведёт корректно, но retrieval может промахнуться.
- **Очень короткие файлы (<100 слов)** могут вообще не попасть в top-k. Объединяй короткие конспекты в один файл.
- **Дубликаты материала** между курсами при `добавь` приводят к смешанной выдаче. Используй уникальные термины в заголовках.
- **Параметр `--audience`** пока не используется в промпте (зарезервирован под пост-MVP адаптацию длины ответов).
