# Бета-квикстарт — AI Professor

Документ для первого запуска на чистой машине. Цель — за 10-15 минут
дойти от `git clone` до голосового диалога с профессором.

## Что нужно перед стартом

- **Windows 10/11** (или Linux/Mac, но скрипт `setup.bat` ориентирован
  на Windows; ручная установка см. ниже).
- **Python 3.10** (строго 3.10, 3.11+ не поддерживается — несколько
  зависимостей привязаны). Скачать:
  https://www.python.org/downloads/release/python-31011/
  При установке отметь «Add to PATH» и «py launcher».
- **API-ключ** одного из провайдеров: OpenAI / Anthropic / DeepSeek /
  Yandex / Mistral. Для дефолтной OpenAI-конфигурации это **единственный**
  внешний ключ который нужен — RAG-эмбеддинги тоже идут через OpenAI.
- (Опционально) **LM Studio** — если хочешь 100% локальный стек без
  облака. Скачать: https://lmstudio.ai/. Без него тьютор работает на
  одном API-ключе, RAG включён.
- (Опционально) **NVIDIA-видеокарта** для ускорения STT через CUDA. На
  CPU тоже работает, но Whisper медленнее в 3-5 раз.

## Что входит в сборку (запускается автоматически)

- **Vosk-TTS сервер** (`scripts/_run_vosk_tts.bat`) — поднимается
  `start_tutor_v2.bat`'ом, никаких действий от тебя.
- **Faster-Whisper STT** — загружается тьютор-процессом, модель
  скачивается в `~/.cache/whisper-models/` при первом запуске
  (~600 МБ).
- **PySide6 board** — стартует тем же bat-скриптом параллельно.
- **OpenAI embeddings** — используются через тот же `OPENAI_API_KEY`
  что и основная модель, без отдельной настройки.
- **bge-m3 GGUF** — `setup.bat` скачивает специальную версию модели
  (`cm4ker/USER-bge-m3-Q4_K_M-GGUF`, 261 МБ) в
  `resources/embeddings/bge-m3/` для опционального локального стека
  через LM Studio. Можно пропустить флагом `setup.bat --no-bge-m3`.

## Внешние зависимости (опциональные но желательные)

### FFmpeg (нужен для транскрипции видео)

Используется `pydub` для извлечения аудио из видеофайлов
(`Видеоматериалы → Загрузить видео…`). Без него остальной тьютор
работает; падает только видео-пайплайн.

**Windows**:
1. Скачай статическую сборку: https://www.gyan.dev/ffmpeg/builds/
   → раздел «release builds» → `ffmpeg-release-essentials.zip`.
2. Распакуй например в `C:\ffmpeg\`.
3. Добавь `C:\ffmpeg\bin\` в `PATH`:
   `Win+R → sysdm.cpl → вкладка Дополнительно → Переменные среды →
   изменить Path → Создать → C:\ffmpeg\bin → OK ×3`.
4. Проверь: открой новый cmd → `ffmpeg -version` → должна показаться
   версия.

Альтернатива через winget: `winget install Gyan.FFmpeg` (PATH
обновится автоматически после перезапуска cmd).

**Linux**: `sudo apt install ffmpeg` (Debian/Ubuntu) или
`sudo dnf install ffmpeg` (Fedora).

**Mac**: `brew install ffmpeg`.

### NVIDIA CUDA (нужен для GPU-ускорения STT)

Faster-Whisper использует ctranslate2; начиная с версии 4.x CUDA-
библиотеки **вшиты в pip-пакет**, отдельный CUDA Toolkit ставить **не
надо**. Достаточно свежего драйвера NVIDIA.

**Что нужно проверить**:
1. У тебя есть карта NVIDIA (десктоп — RTX 20xx и новее; ноутбук — то
   же поколение).
2. Драйвер NVIDIA установлен и не древний:
   - `nvidia-smi` в cmd должна вернуть таблицу с GPU и версией драйвера.
   - Если команды нет — скачай драйвер: https://www.nvidia.com/Download/index.aspx
3. (Опционально) `setup.bat` сам ставит `onnxruntime-gpu` если
   обнаружит драйвер. Можно вручную:
   `.venv\Scripts\python.exe -m pip install -e ".[gpu]"`.

В `.env`: `STT_COMPUTE_DEVICE="cuda"` (это дефолт). Если GPU не
обнаружится — Faster-Whisper упадёт на CPU автоматически и напишет
в лог.

**Без GPU**: ставь `STT_COMPUTE_DEVICE="cpu"`, всё будет работать
медленнее в 3-5 раз. На современном CPU вполне юзабельно для коротких
реплик; долгие видео транскрибировать ощутимо дольше.

## Шаг 1 — клонировать и установить

```bat
git clone https://github.com/kragger-ra/ai-professor.git
cd ai-professor
setup.bat
```

Скрипт сам:
1. Найдёт Python 3.10.
2. Создаст `.venv/` рядом.
3. Поставит все зависимости (включая Faster-Whisper, Vosk-TTS,
   PySide6, Pedalboard).
4. Скопирует `.env.example` в `.env`.
5. Если есть NVIDIA-драйвер — добавит GPU-ускорение.

Первый запуск займёт 3-10 минут (скачивание ~1.5 ГБ зависимостей).

## Шаг 2 — настроить LLM-ключ

Два пути.

### A. Через UI (рекомендуется)

1. Запусти `start_tutor_v2.bat`.
2. В борде: **Файл → Настройки подключений…**
3. Выбери активного провайдера в dropdown, впиши API-ключ, нажми
   «Сохранить».
4. Закрой обе программы и снова запусти `start_tutor_v2.bat`
   (LLM-клиент читает `.env` при старте).

### B. Вручную через `.env`

Открой `.env` любым редактором, найди свой провайдер и впиши ключ:

```env
USE_LOCAL_LLM="false"
CORE_LLM_MODEL_NAME="openai/gpt-4o-mini"
OPENAI_API_KEY="sk-..."
```

Или для локального LM Studio:

```env
USE_LOCAL_LLM="true"
LM_STUDIO_API_BASE="http://localhost:22227/v1"
LM_STUDIO_MODEL_NAME="google/gemma-4-e4b"
```

(LM Studio качается отдельно: https://lmstudio.ai/.)

## Шаг 3 — запустить и пощупать

```bat
start_tutor_v2.bat
```

Подождёшь ~30 секунд, услышишь «Профессор готов. Спрашивай.» В борде
появится главное окно с доской и чатом.

### Импортнуть тестовый курс

1. **Файл → Курсы → Импортировать курс из .zip…**
2. Выбери `samples/test_courses/01_classical_ml/course.zip`.
3. После импорта в Менеджере курсов появится «Классический МЛ».
   Двойной клик активирует его (либо голосом: «загрузи курс
   Классический МЛ»).
4. Спроси: «Расскажи про логистическую регрессию» — должен ответить
   голосом, на доске появятся ключевые термины и формула.

### Прикрепить методичку как документ

1. **Файл → Документы → Прикрепить файл…**
2. Выбери `samples/test_courses/01_classical_ml/methodology.pdf`.
3. Теперь профессор видит PDF в контексте: «Открой 3-ю главу,
   объясни что там про bias-variance».

### Собрать свой RAG-пакет из методички

1. **Файл → Курсы → Подготовить RAG-пакет…**
2. Перетащи `methodology.pdf` в список файлов.
3. Заполни метаданные: имя, тема, аудитория.
4. Нажми «Собрать» — получишь свой курс в `courses/<твоё_имя>/`.

Интерфейс находится в стадии альфа-тестирования. Большая часть фичей
