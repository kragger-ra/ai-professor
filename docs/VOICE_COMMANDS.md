# Голосовые команды — Тьютор v2

Справочник фраз, которые ИИ-профессор распознаёт как команды (минуя LLM).
Распознавание — по ключевым словам: регистр букв и точная формулировка не
важны, важны корневые слова.

Источник истины: `tutor/brain/commands.py`, `tutor/brain/agent.py`.

## Как профессор слышит

Микрофон слушает постоянно (энергетический VAD — детектор по громкости).
Начало речи мгновенно прерывает озвучку профессора. Пока профессор
говорит, порог срабатывания поднят (анти-эхо) — чтобы перебить, говори
громко и чётко.

Короткие поддакивания фильтруются и до профессора **не доходят**:
«ага», «угу», «понятно», «ясно», «хорошо», «ладно», «ок», «да-да»,
«мгм», «хм», «понял», «логично», «верно», «точно», «согласен».
Для подтверждения говори **«да»** или **«давай»** — они не фильтруются.

## 1. Управление речью профессора

| Намерение | Фразы | Что происходит |
|---|---|---|
| Остановить | стоп, стой, хватит, тихо, молчи, помолчи, подожди, погоди | Профессор немедленно замолкает и сам не продолжает. |
| Продолжить / вернуться | продолжай, продолжи, вернись, вернёмся, дальше, поехали | До-озвучивает прерванный ответ из памяти — без нового обращения к LLM. Работает, только если есть незаконченный ответ. |

«Стоп» — короткая фраза в начале реплики (до 25 символов).

## 2. Подтверждение и отказ

Когда профессор сам задаёт вопрос («…Зачитать?», «Вернёмся к…?»,
«Разобрать его?»):

| Намерение | Фразы |
|---|---|
| Да | да, давай, конечно, хочу, разбери |
| Нет | нет, не надо, не нужно, потом, позже, не хочу |

## 3. Манера ответа

Переключает стиль профессора. Действует до следующей смены манеры.

| Манера | Фразы | Эффект |
|---|---|---|
| Проще | расскажи проще, объясни проще, попроще, простыми словами, короче | Простая лексика, регистр речи вниз. |
| Подробнее | расскажи подробнее, объясни подробнее, подробнее расскажи, строже, больше деталей, академически, развёрнуто | Профессиональная лексика, регистр речи вверх. |
| Как обычно | как обычно, нормально говори, нейтрально | Сброс к нейтральному регистру. |

**Важно:** «расскажи подробнее» **без названия темы** — это смена манеры.
«расскажи подробнее **про** рекурсию» — это запрос мини-лекции (раздел 5).

## 4. Курсы

| Намерение | Фразы | Примечание |
|---|---|---|
| Список курсов | какие есть курсы, покажи список курсов, перечисли курсы, что ты умеешь, что можешь преподавать, что у тебя загружено | Перечисляет доступные пакеты. |
| Загрузить / сменить курс | загрузи курс `<название>`, открой предмет `<название>`, возьми тему `<название>` | Заменяет активный корпус. **Это и есть вербальная смена курса.** |
| Добавить курс к текущему | добавь курс `<название>` | Глагол «добавь» — режим дополнения: текущий корпус не сбрасывается. |
| Загрузить из конкретной папки | загрузи курс `<название>` из папки `<путь>` | |

Глаголы загрузки: загрузи, подгрузи, добавь, открой, возьми, включи, начни.
Слова-предметы: курс, предмет, тему, дисциплину, модуль.

Если сказать просто «загрузи курс» **без названия** — профессор перечислит
доступные курсы и спросит, какой; следующая реплика будет принята как
название.

Название распознаётся нечётко: STT-искажения («персона лаб» ->
«персоналаб», «вайб кодинг» -> «вайбкодинг») профессор сопоставит сам.

## 5. Мини-лекция (запрос развёрнутого ответа)

Запрос подробного рассказа по конкретной теме. Распознаётся по трём
признакам **в одной фразе**:

1. глагол-просьба: расскажи, объясни, опиши, раскрой, поясни, давай,
   можешь, можно, хочу, хотелось бы;
2. слово-глубина: подробнее, поподробнее, детально, поглубже, глубже,
   побольше, развёрнуто, целую лекцию, мини-лекцию;
3. тема: про `<X>` / о `<X>` / об `<X>`.

Примеры:
- расскажи подробнее про рекурсию
- объясни поподробнее о замыканиях
- давай детально про декораторы
- хочу мини-лекцию про классы
- можешь подробнее рассказать про наследование

Профессор переспросит: «Это будет мини-лекция — большой развёрнутый
рассказ. Зачитать?» Ответь **«да»** -> длинный развёрнутый ответ;
**«нет»** -> короткий обычный ответ по той же теме.

## Что командой НЕ является

- Обычный вопрос по теме — идёт в LLM как вопрос.
- Длинная фраза, где «подробно»/«про» встречаются внутри повествования
  («вчера я подробно читал про X…»), мини-лекцию не запускает — нужен
  глагол-просьба и короткая директивная формулировка.
- Пауза/перерыв — отдельной команды нет; используй «стоп» и затем
  «продолжай», когда вернёшься.
