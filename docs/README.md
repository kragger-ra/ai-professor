# Generating the docs

----------

Use [mkdocs](http://www.mkdocs.org/) structure to update the documentation.

Go to the `docs/` folder:

    `cd docs/`

Deploy to GitHub Pages with:

    `mkdocs gh-deploy`

Дополнительно:

Build locally with:

    `mkdocs build`

Serve locally with:

    `mkdocs serve`

Сейчас публикуемые доксы лежат в `docs/help/`, начальный файл в `index.md`
