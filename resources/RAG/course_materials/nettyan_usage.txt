Использование NetTyan — запуск и параметры
Перед запуском убедитесь, что .env настроен правильно. После изменений в .env — открыть новый терминал.


Запуск Docker-воркеров (если используете Fish TTS)
Контейнеры Docker должны быть запущены ДО запуска основного скрипта.
Fish TTS: docker-compose -f docker-compose-tts.yml up --build (из папки docker/filter/)
Простой TTS (без Docker): python simple_tts_server.py — запустить в отдельном терминале и не закрывать.


Активация виртуального окружения
Windows: .venv\Scripts\activate
Linux/MacOS: source .venv/bin/activate


Запуск основного скрипта
Вариант 1: cd src && python main.py [params]
Вариант 2: uv run nettyan [params]


Параметры запуска
r — отключить STT (распознавание речи)
o — отключить слушатель Twitch-чата
f — отключить фильтр
s — не запускать агента автоматически
l — использовать простого чат-агента
Пример тестового запуска (всё отключено): python main.py -rofl
Пример с отключённым Twitch и фильтром: python main.py -of
Полный список параметров — в коде src/main.py.


Важные замечания
После изменений в .env нужно перезапустить терминал и программу.
Иногда требуется полная перезагрузка VS Code или системы, если .env не обновился.
