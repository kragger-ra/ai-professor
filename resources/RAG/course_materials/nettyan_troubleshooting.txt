Устранение проблем NetTyan — типичные ошибки и решения


Проблемы со звуковыми устройствами
Список устройств: запустить src/tts/audio_device.py или в Python: import sounddevice as sd; sd.query_devices()
Типичные устройства: CABLE Output (вход), CABLE Input (выход).
После установки виртуального микрофона обязательно перезагрузить ПК.
На Linux могут быть сложности со звуковыми устройствами — требуется дополнительная настройка.


Windows PowerShell — проблема с VENV
Если venv не активируется в PowerShell (ошибка execution policy):
1. Открыть PowerShell от администратора
2. Выполнить: Set-ExecutionPolicy RemoteSigned
3. На вопрос ответить: A


Проблемы с путями и CuDNN на Windows
CuDNN нужно добавить в PATH Windows: C:\Program Files\NVIDIA\CUDNN\v9.15\bin\12.9
После изменения PATH — перезагрузить ПК и VS Code.
Инструкция по добавлению в PATH: https://remontka.pro/add-to-path-variable-windows/


Проблемы с .env
После изменений в .env: открыть НОВЫЙ терминал, закрыть старый.
Иногда нужно полностью перезапустить VS Code или систему.


RAG не работает
Если RAG крашится при инициализации — попробуйте удалить папку data/rag_vector_store/ и перезапустить.
Для RAG нужен MISTRAL_API_KEY в .env (или локальная embedding-модель в LM Studio).


STT не работает на GPU
Убедитесь: CUDA установлена, CuDNN установлен и добавлен в PATH, ПК перезагружен.
В .env: STT_COMPUTE_DEVICE=CUDA
Установлены GPU-зависимости: uv pip install --group gpu
