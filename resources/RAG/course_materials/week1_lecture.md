## Теория

### Концепция курса

Курс построен на принципе синхронной геймифицированной практики. Студенты создают цифровых AI-персонажей, которые автономно функционируют в Minecraft — играют, общаются с игроками в чате и голосом, ведут трансляции. Ключевая идея: игра как интерфейс между агентом и пользователями. Через игру можно быстро прототипировать, сразу видеть результат и доставлять агента на любой сервер.

Курс разделён на две половины: первая — повторение и запуск baseline (стримерши), вторая — собственный проект студента.

### Архитектура baseline-проекта

Baseline представляет собой автономного агента, который одновременно:
- Играет в Minecraft (выполняет действия через систему команд)
- Общается в текстовом чате игры
- Озвучивает ответы через TTS (text-to-speech)
- Распознаёт голосовой чат через STT (speech-to-text)
- Ведёт прямую трансляцию (YouTube/Twitch)

Агент имеет общий контекст — он понимает и игровые события, и чат одновременно. Управляется LLM, у которой есть набор инструментов (tools). Существует несколько агентных режимов: чат-агент (только диалог), core-агент (автономный, с командами), мультиагент (несколько персонажей).

### Система AltaClev

AltaClev — мод для Minecraft (Java), позволяющий управлять персонажем через команды. Это иерархическая система задач: например, команда `game speedrun` запускает цепочку подзадач (добыть дерево → скрафтить инструменты → ...). Команды пишутся через `@` в чате: `@help` (список команд), `@set` (настройки). Ключевые настройки: `set mobDefense false` — отключить автоматическую контратаку.

Мод даёт полноценного клиентского бота (не Mineflayer), который работает на любом сервере, включая публичные. Агент может делать всё, что может обычный игрок, включая управление курсором.

### Связь Java и Python

Java-часть (Minecraft-мод) и Python-часть (логика агента) связаны через библиотеку Py4J. Мод запускает сетевой сервер на определённом порту, Python-скрипт подключается к нему. Через эту связь передаются: сообщения чата, игровые события, команды агента.

### Формат инструментов агента

Инструменты агента (tools) реализованы как Python-функции. Вместо стандартного JSON-формата используется командный формат: `strike nick`, `save-user-info!`, `speak комментарий`. Такой формат компактнее и позволяет агенту быстрее реагировать. Каждый инструмент — это питоновская функция с описанием, которое передаётся агенту в промпте.

### Выбор LLM для автономных агентов

LLM для автономного агента нельзя выбирать по стандартным бенчмаркам. Модели, лидирующие в бенчмарках (Qwen 3, 3.5, DeepSeek), показывают плохие результаты в автономных сценариях стримерши. Единственная Qwen, работавшая приемлемо — Qwen 2.5 VL.

Лучшие результаты на pipeline стримерши показывает Saiga Nemo (форк Mistral Nemo) — старая модель 2024 года, но стабильно превосходящая новые модели в автономных сценариях. Корреляция между ролеплей-бенчмарками и реальным качеством работы в агенте тоже отсутствует. Вывод: каждую LLM нужно тестировать на конкретном pipeline.

### Нейростриминг: экономика и продвижение

Natyan (стримерша автора) стримила с конца 2022 по 2023 год, набрала 100 подписчиков на YouTube. Первая версия использовала Fred T5 (1.7B параметров) — очень старую LLM. Стримерша играла в SkyWars на публичных серверах, общалась в чате.

Для реальной популярности AI-персонажа недостаточно одного бота. Нужен: личный бренд разработчика (стримить вместе с персонажем), коллаборации с другими VTuber-ами, контент (нарезки, ролики). Пример: Neuro-sama начинала с нейросети для OSU, потом Vedal добавил ChatGPT API, написал промпт — и стала популярной за счёт совместных стримов разработчика и персонажа.

Maria AI (русская нейростримерша на Twitch) набрала ~3000 подписчиков за год только на автономном общении в чате, без участия разработчика — но разработчик активно продвигал через VTuber-комьюнити.

## Практика

### Запуск baseline

1. Установить Minecraft Java Edition
2. Установить мод AltaClev и сопутствующие моды (zoomer-мод и др.) по инструкции
3. Скачать проект с Google Drive (не GitHub)
4. Настроить voice chat в Minecraft (кнопка V): указать микрофон и колонку
5. Запуск Python-части: `python main.py` с параметрами. Базовый запуск (минимум функций): `python main.py --rofl`
6. Параметр `--l` (L на конце) — запуск без агентной части (только чат)
7. Без `--l` — запуск с полной агентной частью (агент начнёт автономно действовать)
8. Веб-интерфейс управления: `localhost:22228` — позволяет отправлять команды от имени агента, давать директивы, просматривать цикл событий и контекст

### Настройка треков хоста

Выбор трека зависит от характеристик компьютера (в основном от видеопамяти). Определяет, какой TTS будет использоваться: эмоциональный (Fish Speech, требует CUDA GPU) или простой (для CPU/Mac).

### Публичные серверы для тестирования

- Mystery World — заходить без voice chat, есть готовые мини-игры: `game sv` (SkyWars), `game mm` (Murder Mystery)
- Сервер без модерации (для тестов с чатом) — агент не будет забанен

### Отключение визуальных элементов для стрима

Команда `@set showTaskChains false` — отключает отображение цепочки задач сверху экрана, чтобы не мешать зрителям трансляции.

## Инструменты и технологии

- **Minecraft Java Edition** — платформа, в которой действует агент
- **AltaClev** — мод для Minecraft, реализующий систему команд и задач для управления персонажем
- **Py4J** — библиотека для связи Java и Python через сетевое соединение
- **Fish Speech** — TTS-система (text-to-speech), работает в Docker-контейнере, требует CUDA GPU
- **LLM (локальные)** — мозг агента; рекомендуются Saiga Nemo, CyaNemo Remix; запускаются через LM Studio или аналоги
- **YouTube Studio / OBS** — для ведения прямых трансляций
- **VTube Studio** — для анимации аватара персонажа (lip-sync, движение глаз)
- **Виртуальные аудиокабели** — для проброса звука TTS в Minecraft voice chat и OBS
- **Neuro-sama** — известный AI-стример (разработчик Vedal), упоминается как референс
- **Whisper** — STT-система (speech-to-text) для распознавания голоса игроков

## Ответы на вопросы студентов

**В: Будут ли VLM-модели (Vision Language Models) затронуты в курсе?**
О: Да, на будущих занятиях. Были эксперименты с VLA-моделями (Vision Language Action), которые управляют курсором напрямую, но результаты пока слабые. Будет отдельная лекция.

**В: Какие подписчики и донаты у Natyan?**
О: 100 подписчиков на YouTube за период стриминга с конца 2022 по 2023 год. Новая версия стримерши публично почти не выступала. Донатов не было — проект полностью бесплатный, все LLM запускаются локально.

**В: Есть ли секреты реализации Neuro-sama?**
О: Зависит от версии. Пение — 100% срежиссировано (готовые скрипты). Первая версия играла в OSU (обучение нейросети на скриншотах). Потом добавили ChatGPT API. Игра в Minecraft — комбинация VLA-модели (рывковые движения курсором) и LLM с контекстом об игровой ситуации (возможно, через промпты с описанием обстановки).

**В: Как выбрать LLM для агента?**
О: Не по бенчмаркам. Нужно запускать и тестировать каждую модель на конкретном pipeline. Saiga Nemo (форк Mistral Nemo) стабильно лучше новых Qwen и DeepSeek в автономных сценариях. Qwen 3, 3.5 — плохо работают. Отдельная лекция по выбору LLM планируется.
