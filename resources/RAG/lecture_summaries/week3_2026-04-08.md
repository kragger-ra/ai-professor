### **Конспект лекции: PersonaLab Workshop — Создание ИИ-персонажей**

### **1. Ключевые концепции и определения**
- **Контекст и его передача**:
  - ИИ-персонаж должен понимать **весь цикл событий** и реагировать на них.
  - Для этого используется **командная система талов** (сокращения команд) для компактной передачи контекста за один проход.

- **РАК-система** (*Random Access Knowledge* или *расшифровка неясных терминов*):
  - Добавляет определения **непонятных ЛМК слов** (например, *"cringe"*) в контекст.
  - Работает как **база данных слов**, подбрасывая ЛМК релевантные определения при обнаружении таких терминов.

- **Идеи (Daily Ideas)**:
  - Случайные подсказки для ЛМК, чтобы разнообразить ответы (например: *"Сегодня отвечай как языковая модель"*).
  - Проблема: идеи могут повторяться → необходимо **удалять использованные идеи** из пула.

- **Промпт-конструктор**:
  - Собирает контекст **при каждом вызове ЛМК** (не в реальном времени, а при старте нового запроса).
  - Включает:
    - Данные о пользователе (`safe_user_info`).
    - События (например, изменения ранга зрителя).
    - Триггеры (см. ниже).

- **Система триггеров**:
  - **Циклический запуск**: ЛМК перезапускается каждые **10–15 секунд** для обновления контекста.
  - **Смарт-триггеры**: Мгновенный запуск ЛМК при **приоритетных событиях**:
    - Сообщения в чате (тег персонажа).
    - Игровые события (смерть, убийство).
    - Жесты или действия игроков.
  - **Триггер-ивент**: Передается в промпт, чтобы ЛМК знала, что её вызвало (например, *"кто тебя затриггерил"*).

- **Проблемы автономных агентов**:
  - **Задержки**: Генерация ответа занимает **3–10 секунд** → итоговая задержка может превышать **20 секунд**.
  - **Неактуальный контекст**: Если агент убит, но цикл не завершен, он продолжит выполнять устаревшие действия.

### **2. Практические инструкции и команды**
#### **Команды для управления ЛМК**
- **`!speak`** (сокращенно `→`):
  - Запускает генерацию ответа от ЛМК.
  - Пример: `!speak Привет, как дела?` или `→ Привет`.
- **`safe_user_info`**:
  - Полная команда для передачи данных о пользователе в контекст.
- **`wait`**:
  - Команда для задержки (в лекции упоминается как **нерабочая**, но активно используемая).

#### **Настройка триггеров**
- **Цикл ожидания**: ЛМК ждет **10–15 секунд** или триггер.
- **Приоритетные триггеры**:
  - Сообщения в чате (тег персонажа).
  - Игровые события (смерть, атака).
  - Жесты игроков.
- **Логирование**:
  - В консоли отображается статус агента:
    - `waiting for trigger` — ожидание триггера.
    - `trigger event found` — сработал триггер.

#### **Работа с РАК-системой**
- ЛМК автоматически ищет в тексте **незнакомые слова** (например, сленг) и подгружает их определения из базы данных.

#### **Проблемы и их решения**
| Проблема | Решение |
|----------|---------|
| Повторяющиеся ответы ЛМК | Добавить **Daily Ideas** (случайные подсказки). |
| Повторяющиеся идеи | Удалять использованные идеи из пула. |
| Большие задержки реакции | Использовать **смарт-триггеры** для приоритетных событий. |
| Неактуальный контекст | Пересобирать промпт **при каждом вызове ЛМК**. |

### **3. Упомянутые инструменты и технологии**
- **ЛМК (Языковая модель)**: Базовый инструмент для генерации ответов (например, ChatGPT).
- **Промпт-конструктор**: Собирает контекст перед каждым запросом к ЛМК.
- **РАК-система**: База данных определений для расшифровки сленга и незнакомых терминов.
- **Система триггеров**:
  - **Циклический запуск** (каждые 10–15 секунд).
  - **Смарт-триггеры** (мгновенный запуск при событиях).
- **Игровые движки** (упомянуто на примере агента *Worshipper* в игре):
  - Агент реагирует на действия игроков (атаки, смерть).

### **4. Задания студентам**
1. **Реализация РАК-системы**:
   - Создать базу данных определений для сленговых слов (например, *"cringe"*, *"рофл"*).
   - Настроить автоматическую подгрузку определений в контекст ЛМК.

2. **Настройка триггеров**:
   - Разработать систему смарт-триггеров для чат-бота:
     - Триггер на тег бота (`@ИмяБота`).
     - Триггер на ключевые слова (например, *"помоги"*, *"атака"*).
   - Обеспечить мгновенный запуск ЛМК при срабатывании триггера.

3. **Оптимизация идей (Daily Ideas)**:
   - Создать пул случайных идей для ЛМК (например, *"Сегодня отвечай как пират"*).
   - Реализовать механизм **удаления использованных идей**, чтобы избежать повторов.

4. **Тестирование задержек**:
   - Измерить время генерации ответа ЛМК (от 3 до 10 секунд).
   - Сравнить задержки при циклическом запуске и при смарт-триггерах.

5. **Анализ контекста**:
   - Проверить, как ЛМК реагирует на:
     - Изменение ранга пользователя.
     - Игровые события (например, смерть агента).
   - Убедиться, что контекст обновляется **при каждом вызове ЛМК**.

6. **Творческое задание**:
   - Придумать **3 уникальные идеи** для Daily Ideas, которые разнообразят ответы ЛМК.
   - Пример: *"Сегодня ты — древний маг, говори архаизмами"*.

7. **Отладка автономного агента**:
   - Сымитировать игровую сцену с агентом *Worshipper*:
     - Запустить цикл обновления контекста каждые 10 секунд.
     - Сымитировать убийство агента и проверить, как быстро он отреагирует при использовании смарт-триггеров.
