# Папка для твоих RAG-пакетов

Сюда положи курсы, которые хочешь загружать **короткой голосовой командой** без диктовки пути.

## Как это работает

Tutor сканирует три директории при коротких командах загрузки:

1. `courses/` (эта папка) — твои пакеты
2. `samples/` — встроенные образцы (вышмат и т.п.)
3. `data/courses/` — runtime-папки

Каждый пакет должен содержать `course_config.yml`. Имя для голосовой команды берётся из поля `course.short_name` (или `course.name` если short_name не задан, или имя самой папки как fallback).

## Пример

```
courses/
├── linal/
│   ├── chapter_1.md
│   ├── chapter_2.md
│   └── course_config.yml  ← short_name: "Линал"
└── physics/
    ├── mechanics.md
    └── course_config.yml  ← short_name: "Физика"
```

Голосом:
> «Загрузи курс линал»

Агент найдёт `courses/linal/`, применит конфигурацию, построит RAG. Без диктовки пути.

## Подготовка пакета через CLI

```powershell
uv run tools\prepare_rag_package.py `
    --source D:\my_lectures `
    --out courses\linal `
    --course-name "Линейная алгебра" `
    --course-topic "векторы и матрицы" `
    --short-name "Линал"
```

Параметр `--short-name` — это и есть то имя, которым потом будешь обращаться голосом.

## Длинная команда (если нужно из произвольного места)

> «Загрузи предмет линал из папки D двоеточие курсы линал»

Эта форма работает по-прежнему, но обычно проще положить пакет в `courses/` и использовать короткую.

## Эта папка в git

Содержимое `courses/` исключено из git (`.gitignore`) — твои пакеты остаются локальными. Этот README закоммичен через явное исключение в `.gitignore`.
