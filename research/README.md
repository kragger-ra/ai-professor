# research/ — материалы разработки и оценки ВКР

Эта папка **не входит в среду исполнения тьютора**. Здесь собраны артефакты
разработки магистерской ВКР «Разработка интеллектуального агента-преподавателя
для практического курса по созданию цифрового персонажа» (Балицкий С.Д.,
ИТМО AI Talent Hub): скрипты экспериментов, отчёты об оценке, материалы
апробации.

Студенту для работы с тьютором эта папка не нужна — назначение репозитория
сместилось с «дистрибутива для студентов» на **артефакт разработки ВКР**.

## Структура

| Папка | Содержимое |
|---|---|
| `eval/` | Скрипты экспериментов: инвентарь стека (`_inventory_*`), оценка RAG-retrieval (`_rag_eval_*`), ablation корпуса (`_corpus_*`), faithfulness (`_faithfulness_*`), внешняя валидация retrieval (`_dragon_*`), вспомогательные (`_rebuild_rag`, `_tag_chunks_subject`, `_scenarios_01_run`) |
| `eval_results/` | Готовые отчёты об оценке + сырые данные: `01_inventory.md`, `02_rag_retrieval.md`, `02b_rag_retrieval_full_corpus.md`, `03_faithfulness.md`, `04_external_validation.md`, JSON-данные прогонов, гистограммы L2 |
| `aprobation/` | Материалы апробации с добровольцами: брифинги, согласия, чек-листы хоста, опросник, pre/post-тесты, лог сессий, разбор багов симуляции |
| `corpus_full/` | Полный 11-недельный корпус курса PersonaLab — использован в ablation расширения RAG (отвергнут, см. `eval_results/02b_*`) |
| `corpus_archive/` | Архив исходных лекционных материалов, выведенных из активного RAG-корпуса при курировании |

## Замечания

- Скрипты в `eval/` исполнялись из корня репозитория (`AI-Professor-Tutor/`) —
  относительные пути в них (`src/`, `.env`, `eval_results/`) рассчитаны на корень.
  Сохранены как точная запись методики; для повторного прогона из новой
  директории пути потребуют корректировки.
- Активная база знаний тьютора (1 неделя курса, 140 чанков) лежит в
  `resources/RAG/course_materials/`, а не здесь.
- FAISS-индексы и БД метрик в репозиторий не входят (`data/` в `.gitignore`).

## Ключевые результаты оценки (сводка)

- Сквозная задержка: TTFT p50 1,4 с, end-to-end ответ p50 3,2 с, «студент-в-студенте» ≈ 3–4 с.
- VRAM пик стека ≈ 3,5 ГБ (RTX 4070 12 ГБ).
- RAG retrieval (внутренняя выборка 27 вопросов): P@1 56 %, P@3 70 %, MRR 0,63.
- Внешняя валидация (RuBQRetrieval, полный бенчмарк): nDCG@10 0,69, hit@1 61 %.
- Faithfulness: 94 % ответов опираются на материал курса, 5 % галлюцинаций.
