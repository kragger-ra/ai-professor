## Часть I. Концепция вайб-кодинга и инструменты

**1.** Что делает человек при работе в режиме вайб-кодинга?

а) Словами описывает, какой результат он хочет получить
б) Пишет код на упрощённом псевдокоде, а инструмент дописывает синтаксис
в) Принимает или отклоняет варианты автодополнения в редакторе
г) Размечает блок-схему алгоритма, по которой инструмент генерирует код

**2.** Чем работа с языковыми моделями в 2022–2023 годах отличалась от современной?

а) В то время модели работали без подключения к интернету, на закрытых корпусах
б) Тогда генерация даже простых конструкций требовала множества правок
в) Тогда инструменты были бесплатными, а платными они стали значительно позже
г) Тогда модели работали только с английским языком и не понимали русский

**3.** Что такое SWE-Bench?

а) Облачная среда исполнения кода, встроенная в Cursor
б) Тариф подписки, открывающий доступ к Codex
в) Бенчмарк, оценивающий модели на задачах работы с кодом
г) Внутренний сборщик проектов, используемый Claude Code

**4.** Что сейчас главное при постановке задачи модели?

а) Применить специальные приёмы и ключевые фразы промпт-инжиниринга
б) Сформулировать запрос как можно короче, чтобы модель не отвлекалась
в) Сначала указать язык программирования, остальное модель додумает сама
г) Внятно и полно описать желаемый результат и границы задачи

**5.** В какой области преимущественно силён Claude Code по сравнению с Codex?

а) В дизайне, планировании и исследовательской проработке задачи
б) В скрупулёзном тестировании и работе над дефектами
в) В работе с большими репозиториями на сотни тысяч строк
г) В выполнении задач без передачи данных на серверы вендора

**6.** Какой инструмент быстрее на типичной задаче (например, сборке лендинга)?

а) Codex — у него меньше промежуточных этапов между запросом и кодом
б) Claude Code — он завершает такую задачу примерно за 3–4 минуты
в) Скорость зависит только от тарифа подписки, инструменты эквивалентны
г) Cursor — он быстрее обоих за счёт локального исполнения

**7.** Как обычно устроена работа сразу с двумя инструментами?

а) Запускают оба параллельно и берут тот результат, что готов раньше
б) Чередуют их вручную, копируя куски кода между ними
в) Назначают один основным и поручают ему обращаться ко второму
г) Используют один инструмент, но в нём переключают разные языковые модели

**8.** Что происходит, если модели не дать никакого образца-референса?

а) Модель отказывается выполнять задачу и просит образец
б) Модель ставит работу на паузу до получения уточнений
в) Модель тратит больше времени, но результат получается оригинальнее
г) Модель тяготеет к типовому шаблонному решению

## Часть II. Рабочий процесс в Codex и Claude Code

**9.** Что делает режим YOLO (флаг `--yolo`) в Codex?

а) Автоматически подтверждает все действия модели без запроса
б) Удваивает скорость работы за счёт удвоенного расхода лимита запросов
в) Включает самый глубокий уровень размышлений модели
г) Запускает задачу параллельно в нескольких ветках Git

**10.** Что делает команда `init` внутри инструмента?

а) Регистрирует пользователя и активирует подписку на инструмент
б) Анализирует проект и создаёт файл с заметками о нём
в) Создаёт пустой Git-репозиторий в текущей директории
г) Готовит проект к деплою и публикует его в интернете

**11.** Что такое ограничение контекста у языковой модели?

а) Лимит на число запросов в месяц по тарифному плану
б) Максимальный размер одного файла, который модель может прочитать
в) Объём текста, который модель удерживает в работе «в моменте»
г) Ограничение на число одновременно открытых проектов

**12.** Чем Plan Mode отличается от обычного режима по правам?

а) В Plan Mode модель может менять файлы, но не может удалять их
б) В Plan Mode модель работает быстрее за счёт упрощённой генерации
в) Различий по правам нет, отличается только цвет интерфейса
г) В Plan Mode у модели только право чтения, в обычном — право записи

**13.** Что переключает команда `model`?

а) Уровень глубины размышлений модели
б) Выбор между Claude Code и Codex прямо из текущей сессии
в) Язык программирования, на котором пишется проект
г) Версию модели на самую новую из доступных по подписке

**14.** Что делает команда `review`?

а) Откатывает проект к предыдущему сохранённому состоянию
б) Переводит инструмент в режим проверки внесённых изменений
в) Отправляет код на ревью другому пользователю инструмента
г) Запускает автоматическое исправление найденных дефектов

**15.** Что такое коммит (commit) в Git?

а) Отправка готовой версии проекта на сервер вендора инструмента
б) Запуск проекта в режиме автоматической проверки на ошибки
в) Запись текущего состояния изменений в историю проекта
г) Объединение содержимого нескольких веток в одну ветку

**16.** Что такое ветка (branch) в Git?

а) Отдельный файл с резервной копией всего проекта
б) Группа коммитов, помеченных одинаковым тегом версии
в) Список разработчиков, имеющих доступ к проекту
г) Параллельная копия истории изменений с собственным именем
