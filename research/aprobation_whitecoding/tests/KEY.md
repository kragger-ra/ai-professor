# Ключи к тестам — курс «Вайб-кодинг»

> ⚠️ **НЕ ВЫДАВАТЬ ДОБРОВОЛЬЦАМ.** Только для проверки ведущим.

3 параллельных набора по 16 вопросов: тест 1 (входной), тест 2 (после чтения
материала), тест 3 (после тьютора). Каждый набор проверяет **одни и те же
16 концептов** (8 на тему «Концепция и инструменты» + 8 на тему «Рабочий
процесс»), но другими формулировками и порядком вариантов — это защита от
запоминания вопросов между тремя замерами.

Балл = число правильных из 16. Пустой ответ = «не знаю», не штрафуется.

## Методические замечания (для аудита на защите)

1. **16 вопросов на тест, 2 темы по 8.** Достаточно дискриминирующих пунктов
   для оценки Δ при трёх замерах (pre → mid → post).
2. **3 параллельные формы, не повтор одного теста.** Концепты те же, но
   формулировки вопроса, формулировки вариантов и позиция верного ответа
   различны во всех трёх замерах (см. матрицу выше). Это снимает эффект
   запоминания пунктов между замерами.
3. **Дистракторы — правдоподобные заблуждения, а не filler-абсурды.** Каждый
   неверный вариант — это либо смежный реальный механизм курса (Fast Mode
   вместо YOLO, `git init` вместо `init`, автодополнение Copilot вместо
   вайб-кодинга), либо частично верное утверждение, либо типичная ошибка
   новичка. Угадать, не зная материала, тяжело.
4. **Длина вариантов выровнена** внутри каждого вопроса. Проверено
   автоматически: ни в одном вопросе правильный ответ не является самым
   длинным с разбросом > 15 символов от самого короткого варианта.
5. **Ловушки — на неправильных вариантах.** Длинные/«учебниковые»
   формулировки сознательно располагаются среди дистракторов. Незнающий
   человек, ищущий «развёрнутый правильный ответ», скорее выберет ловушку.
6. **Позиции верных ответов сбалансированы 4/4/4/4** в каждом наборе — защита
   от угадывания по позиционному паттерну.
7. **Межвопросный контекст устранён.** Формулировка одного вопроса не
   содержит подсказки к ответу на другой; пересечения по ключевым словам
   проверены автоматически и оставлены только там, где смыслы концептов
   независимы (например, «файл-контекст проекта» в Q10 и «контекстное окно
   модели» в Q11 — разные сущности).

## Порог для гипотезы «обучение состоялось»

- Прирост Δ = (тест 3 − тест 1) ≥ +3 балла из 16 на доброволца, при тест 3 ≥ 9.
- Среднее Δ по группе ≥ +1.5 балла.
- Дополнительно фиксируется промежуточный замер: Δ_текст = (тест 2 − тест 1) —
  вклад самостоятельного чтения; Δ_тьютор = (тест 3 − тест 2) — вклад работы
  с тьютором. Это позволяет разделить эффект тяжёлого текста и эффект тьютора.
