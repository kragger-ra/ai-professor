# Конспект лекции — Неделя 11-12

## 1. Проект Святослава — игра на Unity с LLM-агентом

**Суть:** от первого лица, игрок заперт в доме и должен выбраться, взаимодействуя с NPC-агентом (девушкой), управляемым языковой моделью.

### Техническая база
- Агентом управляет локальная модель на 4B параметров, зашитая прямо в билд через пакет «LLM for Unity»
- Тестировалась и 14B, но она слишком медленно думает — 20-25 секунд на ответ. С 4B — 2-7 секунд
- Предусмотрены текстовые заглушки на время генерации, чтобы игрок не ждал в тишине
- Модель можно выбрать из встроенного каталога, загрузить с Hugging Face или подключить внешний URL/API по желанию игрока

### Системы агента
- Четыре состояния настроения (нейтральное, счастливое, злое, подозрительное)
- Шкала симпатии к игроку — от ненависти до привязанности, зависит от реплик и действий
- Счётчик оправданий — три штуки, после исчерпания агент больше не принимает оправданий, даже оригинальных

### Навигация и восприятие
- Комнаты размечены «room zones». Агент осознаёт, в какой комнате находится, и привязывает контекст диалога к текущему местоположению
- Точки интереса задают координаты для перемещения
- Агент различает запросы на разговор и запросы на действие (по наличию глаголов в реплике): если просят «подойти» — сначала вызывает тул перемещения, потом отвечает

### Сюжетная концепция
- Игрок просыпается в доме, не понимая, где он. Нужно либо убедить агента открыть дверь, либо найти способ самому
- Обсуждались варианты: яндере (отвергнуто автором как раздражающий троп), вирус-локдаун с андроидом-сиделкой на сбойной «китайской прошивке», мама-не-выпускает
- В доме — ноутбук агента с дневником наблюдений; чтобы взломать — нужно обойти LLM-защиту (prompt injection), при этом ограничено время, пока агент не застукает

### Ассеты и планы
- Бесплатные ассеты из Unity Asset Store. Два дома — современный и алхимический (Alchemist House) для возможного средневекового хоррор-сегмента
- Планы: инвентарь для обоих персонажей, текстуры и анимации NPC, взаимодействие с окружением (лечь на кровать, подойти к плите), сюжетные предметы, регистрация на itch.io, альфа-билд к 13-14 числу

## 3. Проект Семёна — AI-Профессор

**Суть:** цифровой преподаватель, который читает лекции голосом, взаимодействует со студентами в реальном времени, адаптируется под каждого.

### Архитектура (мульти-модельная)
- **Mistral API** (бесплатный) — основная модель для быстрого диалога со студентом
- **Claude Opus** — суммаризация, конспекты, подготовка структуры лекции, обработка сложных вопросов. Работает «за кулисами», пока Mistral общается
- **Claude Haiku** — мета-агент: анализирует настроение студента, манеру общения, записывает в мета-знания (что студент знает, где ошибается, что любит/не любит). Подсказывает Mistral, как вести объяснение дальше

### TTS
- Vosk TTS — процессорный (CPU), русскоязычный. Быстрый, дешёвый в inference
- Требует серьёзного препроцессинга: цифры нужно прописывать буквами, англицизмы транслитерировать, знаки препинания обрабатывать
- Без этого — артефакты, шипение, скачки интонации
- Эмоции модель формально не поддерживает, но читает с интонациями самостоятельно

### Персонализация
- Через RAG — запоминает имя, фамилию, род деятельности
- Постепенно дописывает профиль: что студент знает, где ошибается, характер, манера общения
- Смена базы знаний превращает профессора в преподавателя любого предмета

### Режим лекции
- Модуль готовит тезисы на основе RAG, затем профессор читает по ним, каждый раз немного по-другому
- Делает паузы между блоками
- Если студент перебивает — останавливается, слушает, различает шум и осмысленный вопрос
- Структура — 18 блоков

### Модуль юмора
- Шанс шутки настраивается (по умолчанию 7%, в демо повышали до 30% и 90%)
- На 90% профессор пошутил про «8 секунд как прогресс 2005 года», но повторял целые блоки перед шуткой

### Известные баги
- Мета-агент Haiku не различал свою речь и речь студента, принимал повторения за издевательство, и провоцировал Mistral реагировать агрессивно

### Подключение к Zoom
- Два клиента Zoom (один для ИИ, один для человека)
- Виртуальные кабели через VoiceMeeter Banana
- Разработка велась с Claude Code — оперативная починка багов прямо на демо

## 4. Общая дискуссия

### Провайдеры моделей
- **Mistral** — единственный бесплатный API без VPN из РФ, но самая слабая модель, часто падает (проблемы каждый день)
- **Google** — хорошие лимиты, но VPN
- **AWS-провайдер для Opus** — задержка до 15 секунд, плюс потенциальная блокировка

### Локальные модели vs. API
- Зашивать LM Studio в процесс игры неудобно для конечного пользователя (нужно ставить стороннее ПО)
- Обсуждалась схема: внутренняя модель по умолчанию + опция подключения внешнего API через ключ
- Также обсуждался тонкий клиент (серверные вычисления, как в CS:GO)

### Стриминг и нейростримерши
- Обсуждались нейростримерши в ру-сегменте Twitch, Ивангай с AI-клоном, канал «4D» с 3D нейростримершей
- Наблюдение: людям нравится, когда нейронка их унижает

### Claude Code как инструмент разработки
- Все участники активно используют
- Обсуждалось, что привычка к нему создаёт зависимость и страх «откатиться в каменный век» при отключении

## 5. Переработка Неттян (пайплайн стримерши)

Влад описывает, что пайплайн стримерши (Неттян) сильно переработан за последние несколько недель.

### Модель
- **Gemma 26B** (загружается через LM Studio, занимает 12 ГБ VRAM)
- Для менее мощных карт предлагается **Gemma E4B** (~7 ГБ) или **Qwen 3.5 9B** как альтернативы
- Mistral, используемый ранее, назван «самой отстающей моделью на сегодняшний день»

### Prompt Caching в LM Studio
- Кэшируется неизменяемая часть промта, а новые события (из Minecraft) дописываются в конец контекста
- При промте в 20 000 токенов достигнута задержка **~1 секунда на ответ**
- Модель реагирует на игровые события мгновенно
- Prompt Caching включается автоматически в LM Studio; галку «Unified Cache» рекомендовано не трогать (хуже)

### Проблема холодного старта
- Если не обращаться к модели больше секунды, задержка вырастает до 3+ секунд
- Решение — **heartbeat-пакеты**: каждую секунду отправляется пинг-запрос на LM Studio, даже когда модель не генерирует
- Модель остаётся «прогретой» и отвечает мгновенно. Ответ сразу уходит в TTS

### Рекомендация для проекта Святослава
- На RTX 4070 (12 ГБ) ожидается скорость **~60-70 токенов/секунду**
- Если скорость всего 3 токена/сек — модель не загрузилась на GPU (частая ошибка: в LM Studio нужно вручную выставить все слои на GPU через ползунок «layers to GPU»)
- При стриминге — ~5 секунд прогрев, потом потоковая генерация; в худшем случае 10 секунд ожидания
