# Классический ML и метрики качества

Тестовый RAG-курс плюс методичка. Поставляется с репозиторием, чтобы
сразу было что показать.

## Файлы

- **`course.zip`** — упакованный RAG-пакет с конфигом и материалами.
  Импортируется в борде через **Файл → Курсы → Импортировать курс из
  .zip…**. После импорта курс появится в Менеджере курсов; активируй
  двойным кликом или через quick-switcher в тулбаре.

- **`methodology.pdf`** — методическое пособие. Можно использовать
  двумя способами:
  1. **Открыть в борде** как документ-контекст
     (Файл → Документы → Прикрепить файл…). Тогда ИИ-профессор сможет
     ссылаться на него в ответах.
  2. **Прогнать через Builder**: Файл → Курсы →
     Подготовить RAG-пакет… → перетащи PDF в список файлов, заполни
     метаданные, собери. Получится твой собственный курс на этом
     материале, отдельно от `course.zip`.

## Что внутри

Темы: линейные модели, деревья, бустинг, SVM, kNN, кластеризация,
валидация, регуляризация, bias-variance, A/B-тесты, CUPED, метрики
для классификации, регрессии, ранжирования и компьютерного зрения,
калибровка.

Аудитория: ML-инженер или аналитик, систематизирующий знания по
классическому ML и продакшен-оценке моделей.
