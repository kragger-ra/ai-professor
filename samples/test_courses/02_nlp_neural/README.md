# Нейросети и NLP

Тестовый RAG-курс плюс методичка по нейросетевому глубокому обучению
и обработке естественного языка.

## Файлы

- **`course.zip`** — упакованный RAG-пакет. Импорт через
  **Файл → Курсы → Импортировать курс из .zip…**, после чего курс
  появится в Менеджере курсов.

- **`methodology.pdf`** — методическое пособие. Используется как:
  1. **Документ-контекст в борде** (Файл → Документы →
     Прикрепить файл…) — ИИ-профессор может ссылаться на него.
  2. **Источник для своего RAG-пакета** через Builder
     (Файл → Курсы → Подготовить RAG-пакет…).

## Что внутри

Темы: feed-forward сети, обучение и оптимизация, attention и
трансформеры, токенизация, эмбеддинги, языковые модели, fine-tuning,
RAG, классические NLP-задачи (sentiment, NER, QA), современные
инструменты и фреймворки.

Аудитория: разработчик, систематизирующий знания по нейросетевому DL
и NLP, готовящийся к инженерным собеседованиям или собирающий
прикладной проект.
