# Образцы RAG-пакетов

Папка для готовых тестовых курсов, поставляемых вместе с репозиторием.

## `test_courses/`

Две пары «упакованный курс + методическое пособие» — то, с чего
тестеру удобно начать после первой установки:

- **`01_classical_ml/`** — Классический ML и метрики качества.
- **`02_nlp_neural/`** — Нейросети и NLP.

В каждой папке `course.zip` (импортируется в Менеджер курсов через
**Файл → Курсы → Импортировать курс из .zip…**) и `methodology.pdf`
(можно прикрепить как документ-контекст или прогнать через Builder,
чтобы собрать собственный пакет).

Подробнее — `README.md` внутри каждой папки.

## Свои курсы

Можно положить любую папку с `course_config.yml` сюда — Tutor найдёт
её при поиске «загрузи курс …» наряду с папками из `courses/`. Но
рабочие курсы, которые ты собираешь сам, по умолчанию складываются
в `courses/` (Builder пишет именно туда).
