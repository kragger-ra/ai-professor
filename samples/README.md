# Образцы RAG-пакетов

Готовые тестовые курсы для проверки работы Tutor без подготовки собственных материалов.

## `vyshmat/` — Высшая математика

Три раздела (`.md`):
- `01_proizvodnaya.md` — производная: определение, геометрический и физический смысл, правила, таблица
- `02_integral.md` — интеграл: неопределённый и определённый, формула Ньютона-Лейбница, методы
- `03_matrix.md` — матрицы: операции, определитель, обратная, ранг, применение в ML

Плюс `course_config.yml` с метаданными курса.

### Использование

После запуска Tutor (`start_professor_tutor.bat`) скажи в микрофон:

> «Загрузи предмет Вышмат из папки N двоеточие exam local llm experement A I дефис Professor дефис Tutor samples вышмат»

Или подставь свой путь, если репо склонирован в другое место.

Если голосовая команда некомфортна — для проверки можно скопировать пакет в простой путь, например `D:\vyshmat\`:

```powershell
xcopy samples\vyshmat D:\vyshmat\ /E /I
```

И тогда голосом: «Загрузи предмет Вышмат из папки D двоеточие вышмат».

### Что можно проверить после загрузки

- «Расскажи мне про производные»
- «Что такое формула Ньютона-Лейбница»
- «Объясни умножение матриц на примере»
- «В чём геометрический смысл интеграла»

Темы за пределами этих трёх разделов агент должен честно отказываться разбирать («материалов нет»).
