# Интеграл

## Неопределённый интеграл

**Первообразной** функции `f(x)` называется такая функция `F(x)`, производная которой равна `f(x)`:

$$F'(x) = f(x)$$

Множество всех первообразных функции `f(x)` называется **неопределённым интегралом** и обозначается:

$$\int f(x) \, dx = F(x) + C$$

где `C` — произвольная константа интегрирования. Константа появляется потому, что производная константы равна нулю — добавление любой постоянной к первообразной не меняет её производную.

## Определённый интеграл

**Определённым интегралом** функции `f(x)` от `a` до `b` называется предел интегральных сумм при бесконечном измельчении разбиения отрезка `[a, b]`:

$$\int_a^b f(x) \, dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(\xi_i) \cdot \Delta x_i$$

где `Δxᵢ` — длины частичных отрезков, `ξᵢ` — произвольные точки внутри них.

## Геометрический смысл

Если функция `f(x) ≥ 0` на `[a, b]`, то определённый интеграл равен **площади криволинейной трапеции**, ограниченной графиком функции, осью абсцисс и вертикальными прямыми `x = a`, `x = b`.

Если функция меняет знак — интеграл даёт **алгебраическую сумму** площадей (части под осью считаются со знаком минус).

## Формула Ньютона-Лейбница

Связь между неопределённым и определённым интегралами устанавливает основная формула интегрального исчисления:

$$\int_a^b f(x) \, dx = F(b) - F(a)$$

где `F(x)` — любая первообразная функции `f(x)`. Эта формула позволяет вычислять площади и другие интегральные величины через нахождение первообразной, не прибегая к предельному переходу в интегральных суммах.

## Таблица основных интегралов

| Интеграл | Результат |
|---|---|
| `∫ dx` | `x + C` |
| `∫ x^n dx` (n ≠ -1) | `x^(n+1) / (n+1) + C` |
| `∫ dx/x` | `ln|x| + C` |
| `∫ e^x dx` | `e^x + C` |
| `∫ sin(x) dx` | `-cos(x) + C` |
| `∫ cos(x) dx` | `sin(x) + C` |
| `∫ dx/cos²(x)` | `tan(x) + C` |
| `∫ dx/(1+x²)` | `arctan(x) + C` |
| `∫ dx/√(1-x²)` | `arcsin(x) + C` |

## Основные методы интегрирования

**Замена переменной (подстановка):**
Если `x = φ(t)` и `dx = φ'(t) dt`, то:
$$\int f(x) \, dx = \int f(\varphi(t)) \cdot \varphi'(t) \, dt$$

**Интегрирование по частям:**
$$\int u \, dv = u \cdot v - \int v \, du$$

Применяется когда подынтегральное выражение представляется в виде произведения, и одна часть легко дифференцируется, другая — легко интегрируется.

**Метод разложения на простейшие дроби** — для рациональных функций. Дробь разлагается на сумму простейших, каждая интегрируется по табличным формулам.

## Пример

Вычислим `∫ x · e^x dx` методом интегрирования по частям.

Положим `u = x`, `dv = e^x dx`. Тогда `du = dx`, `v = e^x`:

$$\int x \cdot e^x \, dx = x \cdot e^x - \int e^x \, dx = x \cdot e^x - e^x + C = e^x (x - 1) + C$$

## Применения

Интегральное исчисление применяется для вычисления:

- **Площадей** криволинейных фигур
- **Объёмов** тел вращения и тел сложной формы
- **Длин дуг** кривых
- **Работы** переменной силы
- **Массы** тел с переменной плотностью
- **Математических ожиданий** в теории вероятностей (интеграл от плотности распределения)

В машинном обучении и обработке сигналов определённые интегралы используются в формулах свёртки, преобразовании Фурье и оценке функций потерь по непрерывному распределению.
